# BLM-Air-demo

这是一个面向投资人演示的前端 Demo 工程，用于展示“通用低空世界模型”如何把低空空间、空域规则、无人机资源、动态环境、任务意图、风险约束、执行反馈和结果交付统一建模。

当前处于 **V0.1 / 阶段 1：工程骨架搭建**。

## 技术栈

- Vite
- React
- TypeScript
- 普通 CSS
- SVG 自绘模拟地图

## 启动方式

```bash
npm install
npm run dev
```

## 配置高德地图

世界总览页支持接入高德地图 JS API 2.0 的兴隆湖真实深色底图。

1. 登录高德开放平台控制台。
2. 进入「应用管理」，创建新应用。
3. 在应用中「添加 Key」。
4. 服务平台选择「Web端(JS API)」。
5. 获取 `Key` 和 `安全密钥`。
6. 在项目根目录复制 `.env.example` 为 `.env.local`。
7. 填入：

```bash
VITE_AMAP_KEY=你的高德Web端JSAPI_Key
VITE_AMAP_SECURITY_CODE=你的高德JSAPI安全密钥
```

8. 重启开发服务器：

```bash
npm run dev
```

说明：2021 年 12 月 02 日之后申请的高德 JS API Key 需要配合安全密钥使用。当前 Demo 采用前端明文方式配置安全密钥，适合本地演示；生产环境建议使用代理服务器转发方式，避免安全密钥暴露。

### 语义图层校准

高德地图使用 GCJ-02 坐标。当前兴隆湖语义图层配置在：

```text
src/data/xinglongAmapLayers.ts
```

配置高德 Key 后，世界总览地图右下角会显示“点击地图读取 GCJ-02 坐标”。校准方式：

1. 打开世界总览。
2. 点击真实地图上的湖岸、科学城、服务区、道路等边界点。
3. 记录右下角显示的经纬度。
4. 将坐标写入 `xinglongAmapLayers.ts` 中对应的 `path`。
5. 保存后刷新页面检查覆盖物是否贴合真实底图。

建议先校准以下图层：

- `water`：兴隆湖真实湖体边界
- `wetland`：A 巡检区
- `scienceCity`：B 应急点
- `logistics`：C 配送区
- `urbanCore`：障碍密集 / 风险推演区
- `xinglongTaskCorridor`：任务通道
- `xinglongRiskPolygons`：风险区域
- `xinglongResourceMarkers`：Dock 和无人机位置

## 模拟数据边界

本 Demo 使用模拟数据，不连接真实无人机、不接真实空域审批、不调用真实地图 API、不调用真实大模型 API，不代表真实运营结果。

真实部署需要接入无人机设备、空域规则、气象数据、通信环境和现场运行规范。
